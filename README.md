# Te5st App - FIJLKAM

This is a Kotlin Multiplatform project targeting Android, iOS for FIJLKAM UDG & Competitions management.

* [/androidApp](./androidApp) contains the Android application.
* [/iosApp](./iosApp) contains the iOS application.
* [/shared](./shared/src) contains shared Compose Multiplatform code and Supabase PostgREST repository integration.

### Running the app
- Android app: `./gradlew :androidApp:assembleDebug`
